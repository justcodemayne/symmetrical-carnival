# symmetrical-carnival
Gasometer Project


GasWatch – MacOs Crypto Gas Fee Monitor

This is a highly performant native menu bar app for MacOS & (Windows soon) created specially for crypto traders and DeFi lovers to monitor gas prices on blockchain network.

Main Features
Real-Time Menu Bar Widget: Real-time value of the gas prices (Gwei) and status colors indicator.
Threshold Notification: Notification which pops up once the network gas price is dropped to the desirable level.
Multinetwork Monitoring: Real-time monitoring of major networks and Layer-2 scaling solutions.
Native MacOS: Designed to have a minimal impact on the battery power consumption (less than 1% of CPU load) and support of Dark/Light modes out of the box.
Fast Estimator: Calculating the price of operations in USD.

Tech Stack & Architecture
Language and GUI: Python, Custom GUI / Menu bar wrapper.
Architecture: The modular system with 11 modules implemented, optimized for background polling.
Deployment: Native .app pre-compiled binary file and automation of deployment processes
